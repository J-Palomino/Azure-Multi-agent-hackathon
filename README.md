# openDispatch

A Hackathon Submission by Ximena Bustamante and Juan Palomino

## Overview
openDispatch is a multi-agent dispatching system designed to address the logistical challenges of call routing and dispatching for understaffed organizations. Built as a hackathon project, openDispatch leverages Microsoft Azure to deliver intelligent, automated call handling and routing.

## Problem Statement
Many organizations, especially those with limited staff, struggle to efficiently route incoming calls and dispatch resources. Traditional systems are often manual, slow, and prone to errors, leading to missed opportunities and inefficient operations.

## Solution
openDispatch enables users to call a central line, where their call is intelligently routed to the appropriate channels using multiple voice agents hosted in Azure. The system automatically adds metadata and can execute server-side actions, streamlining the dispatching process and reducing the burden on human operators.

## Features
- Centralized call-in line for users
- Intelligent call routing using Azure-hosted voice agents
- Automated metadata tagging for calls
- Execution of server actions based on call context
- Designed for scalability and ease of integration

## Tech Stack
- **Microsoft Azure**: Cloud infrastructure and voice agent hosting
- **Multi-Agent System**: Multiple voice agents collaborate to handle and route calls
- **Serverless Functions/Server Actions**: For metadata processing and dispatch logic
